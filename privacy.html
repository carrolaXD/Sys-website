Privacy Policy

Sys is a personal, local-first desktop application for academic information organization. This policy describes the current implemented behavior, and distinguishes it from planned features.

1. Data accessed

When the owner authorizes a connection, Sys can retrieve academic information through the Instituto Superior Técnico Fénix API, including course and enrollment information, timetables and evaluations.

The Gmail integration requests https://www.googleapis.com/auth/gmail.readonly. It can read messages, selected headers, labels, timestamps, message and thread identifiers, message body text, and attachment metadata in authorized mailboxes. It does not download attachment contents in its current implementation; it cannot send, modify, archive or delete messages.

Each personal or institutional Google account must be authorized separately. Accounts do not inherit each other's access permissions. Google Calendar and Google Drive are planned, not yet implemented. When added, they will request separate, purpose-limited read-only permissions, with updated disclosures.

2. Purpose and use

Authorized data is used solely to synchronize, organize and make the owner's information searchable within Sys. It is not used to advertise, sell data, build advertising profiles, monitor third parties or train generalized AI or machine-learning models.

3. Storage and security

Synced records are stored in a SQLite database on the owner's Windows computer. OAuth credentials and access/refresh tokens are stored in Windows Credential Manager. No Google OAuth codes, tokens, messages or academic documents are sent to this GitHub Pages website.

Sys does not currently operate a hosted service for synchronized data, and does not transfer synced Gmail messages to ChatGPT or other external AI services. A future optional AI integration would require a separate implementation and appropriate privacy review and disclosures before any Google data is transmitted outside the local computer.

4. Sharing and disclosure

Sys does not sell or share Google user data with advertisers, data brokers, or unrelated third parties. Requests to Google APIs and Fénix are necessary to access the owner's authorized information. The owner controls the local installation. Any future third-party integration will be assessed separately under applicable Google API rules.

5. Retention, deletion and revocation

Records remain on the owner's computer until the local database is deleted or managed by the owner. The owner can revoke Google's authorization from their Google Account connections. Revocation stops future authorized API access, but does not automatically delete previously synchronized local records; local deletion is a separate action. Workspace administrators may impose additional access restrictions.

6. This informational website

The public website contains no login, tracking scripts, analytics, advertising, or forms, and does not set its own cookies. It is hosted by GitHub Pages; GitHub may process technical request information, such as IP addresses and security logs, under the GitHub Privacy Statement.

7. Google API Limited Use

Sys's use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only for the features described here, with authorized scopes and user control.

8. Updates and contact

This policy may be updated as integrations are implemented or their data practices change. The effective date above identifies the current version. For questions, use the developer contact details shown in the Google OAuth consent screen.
