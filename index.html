Local-first · Personal use · Read-only connections

Academic information, in one private place.

Sys is a personal Windows desktop backend that brings together academic records and email for search and organization. It is not an online service and does not offer public user accounts.

Privacy by architecture

Your information stays on your computer.

Sys is designed to synchronize records into a local SQLite database on the owner's Windows computer. OAuth credentials and tokens are protected using Windows Credential Manager. Each Google account is authorized independently.

This website provides information only: it does not run authentication, collect OAuth codes or receive synchronized email or academic records. Google authorizations use the system browser and a temporary localhost callback.

Use of Google API data

Sys's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Read the privacy policy for what is accessed, why, and where it is stored.
